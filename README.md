# Resume Website Template

A polished, responsive one-page resume website built as a single static `index.html` file. The default page is filled with a realistic fictional resume so you can see what a finished version looks like before replacing the content.

It includes:

- Full-screen resume hero
- Profile, experience, projects, education, links, and skills sections
- Realistic example accomplishments and project descriptions
- Light and dark theme toggle
- Print-friendly styling for saving as a PDF
- No build step or external dependencies

## Customize

Edit `index.html` and replace the fictional sample details for Maya Chen with your own name, role, contact links, experience, projects, education, and skill entries. The sample content is meant to model tone, specificity, and structure rather than act as placeholder filler.

## Publish With GitHub Pages

1. Open the repository settings.
2. Go to **Pages**.
3. Set the source to the `main` branch and root folder.
4. Save the settings.

GitHub Pages will serve the site from the repository root.
